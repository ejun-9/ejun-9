# Eun Ji Jung

I'm a product designer, and I write the code for most of what I design. For four years at Komodo Health I designed the cohort builder that clinical data scientists and epidemiologists use to define patient populations. Lately I build small tools that let AI coding agents read a design system and Figma feedback.

[Portfolio](https://eunji.design) · [LinkedIn](https://www.linkedin.com/in/ejung96)

### Research interest

Trust calibration and appropriate reliance when a healthcare system acts on behalf of patients and caregivers. People often turn down an automated option even when it performs better, and current trust measures can't tell whether that's distrust or a choice to stay in control. I want to work on telling those apart.
